# Ikorniy Sport App — MVP трекер тренировок

Мобильное веб-приложение для ведения записей тренировок (замена Google Таблицы).
Стек: **Nuxt 3 (Vue 3) + Vuetify + Pinia + PocketBase**.

## Что реализовано (MVP)

- Список тренировочных дней (аналог вкладок в таблице), можно добавлять новые.
- Внутри дня — список упражнений (можно добавлять, задавать число подходов).
- Форма «Новая тренировка»: дата, для каждого упражнения — рабочий вес,
  целевое число повторений, результат по каждому подходу, уровень боли (0–5,
  как в исходной таблице) и заметка.
- История тренировок по дню в виде разворачиваемых карточек, с подсветкой,
  если уровень боли ≥ 3 (по инструкции из таблицы — сигнал снизить нагрузку).
- Удаление записей.
- Один пользователь, без авторизации — специально для быстрого MVP.

## Локальный запуск

1. Установить зависимости:
   ```bash
   npm install
   ```
2. Запустить PocketBase (бэкенд с БД), отдельный процесс на порту **8091**,
   чтобы не конфликтовать с другими проектами:
   ```bash
   npm run pb
   ```
   Данные хранятся в `pb/pb_data` (в `.gitignore`, не коммитится).
   Схема коллекций создаётся автоматически из миграции в `pb/pb_migrations`.

   Админка PocketBase: http://127.0.0.1:8091/_/
   Логин суперпользователя создан локально: `admin@ikorniy.local` / `ChangeMe123!`
   (смените пароль перед продакшеном: `pocketbase superuser upsert ...`).

3. Запустить само приложение:
   ```bash
   npm run dev
   ```
   Откройте http://localhost:3000 (на телефоне — через IP машины в локальной сети).

## Структура данных

- `training_days` — тренировочные дни (вкладки из таблицы).
- `exercises` — упражнения внутри дня.
- `sessions` — конкретная тренировка (дата + общий комментарий).
- `exercise_entries` — результат по каждому упражнению за сессию
  (вес, целевые повторения, повторения по подходам, боль, заметка).

## Дальнейшие шаги (не входят в MVP)

- Авторизация тренера/клиентов, если понадобится несколько пользователей.
- Графики прогресса по весу/повторениям.
- Экспорт истории в PDF/Excel.
- Деплой PocketBase + Nuxt на сервер (аналогично соседнему проекту в этом репозитории).
